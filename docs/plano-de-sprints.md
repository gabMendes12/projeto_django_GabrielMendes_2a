# Plano de sprints

## Quadro do Jira

O quadro deve usar as colunas indicadas no guia da disciplina:

`To Do` → `Em desenvolvimento` → `Desenvolvido` → `Em validação` → `DONE`

Cada sprint deve ter uma meta, histórias ou documentação no backlog, subtarefas distribuídas entre os membros e uma evidência visual anexada ao README.

## Sprint 01: análise e descoberta

**Objetivo:** entender o problema, analisar alternativas e registrar o produto.

- Documento de análise de cinco competidores.
- Benchmark comparativo.
- Requisitos obtidos.
- Seis histórias em BDD.
- README com equipe e produto.
- Criar o item de documentação no Jira e suas subtarefas.
